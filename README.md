# MyPaste

一个从零实现的原生 macOS 截图、标注与贴图工具，覆盖截图、取色、标注、贴图与历史记录流程；使用 Swift + AppKit + ScreenCaptureKit，无 Electron、无 Web 运行时、无第三方依赖。

常驻菜单栏，按 **F1 截图**，按 **F3 贴图**。

## 使用说明

本项目从零开始即由 AI 协助完成。为个人使用，可能存在部分问题或BUG，请谨慎使用。

## 功能

### 截图

- 拖拽区域截图、单击自动选中鼠标下的窗口、单击空白处选中整个屏幕。
- 多显示器分别冻结画面（并行采集），选择区域限制在当前屏幕内；个别显示器无法匹配采集源时会明确提示并只覆盖其余屏幕。
- 像素级放大镜：显示十六进制色值、RGB、图像像素坐标；`C` 直接复制颜色。
- 选区支持 8 向手柄缩放、拖动移动、方向键 1px 微调、`Shift` 方向键缩放、`Shift` 拖拽锁定正方形；拖选 / 缩放 / 移动过程中实时显示像素尺寸与选区原点坐标；选区宽或高不足 8pt 时保留细长选区，小于 18pt 时不显示手柄、按移动处理。
- 工具栏显示当前截图像素尺寸，支持复制、保存、贴图、取消。
- 全屏截图快捷键 `⌥F1`：直接复制到剪贴板，可选自动保存。
- 独立取色器：冻结屏幕后单击复制颜色，支持跨屏。
- 截图过程不轮询屏幕，窗口检测只在鼠标移动时进行并做 120ms 节流。

### 标注

| 工具 | 说明 |
| --- | --- |
| 移动 | 调整选区位置 |
| 矩形 / 椭圆 | 可填充或描边，`Shift` 锁定宽高比 |
| 箭头 | 可调颜色、粗细，`Shift` 锁定 45° |
| 画笔 | 平滑曲线 |
| 荧光笔 | 半透明宽笔触 |
| 文字 | 透明底纯文字，无背景色 / 边框；点击原位输入，顶部手柄可拖动输入框；工具栏字号 12–120；提交后可选中移动、双击再编辑、改字号与颜色 |
| 马赛克 | 实时像素化，基于冻结画面采样 |
| 高斯模糊 | Core Image 实时模糊 |
| 序号 | 自动递增的圆形序号 |
| 橡皮擦 | 点击删除命中的标注 |

- 10 种颜色、6 档粗细、形状填充开关；文字使用独立字号菜单。
- 文字提交后自动切回移动工具并选中该文字，可直接拖动、用方向键微调、改字号 / 颜色，或双击重新编辑。
- 50 步撤销 / 重做（包含文字移动、字号与颜色修改）。
- 上次使用的标注工具会在下次截图时保持（文字 / 移动工具不作为初始工具）。
- 所有标注工具坐标统一以选区左上角为原点，编辑预览与最终输出共用同一套渲染器，保证所见即所得。
- 工具栏与快捷键：`V` 移动、`R` 矩形、`E` 椭圆、`A` 箭头、`B` 画笔、`H` 荧光笔、`T` 文字、`M` 马赛克、`U` 模糊、`N` 序号、`X` 橡皮擦。

### 输出 / 贴图

- 复制：PNG + TIFF 以惰性数据写入剪贴板，复制动作不阻塞主线程编码。
- 保存：PNG / JPEG / TIFF，默认格式、JPEG 质量与目录可在设置中修改。
- 复制后自动保存（可选）。
- 复制 / 保存 / 贴图 / 全屏截图成功后显示可自动消失的非模态提示（不抢焦点）。
- 贴图：截图可以直接按 `P` 贴到屏幕原位置；剪贴板中的图片、文本、颜色值可以按 `F3` 生成贴图。
- 文本贴图渲染为深色卡片，颜色值生成色卡并保留原始文本用于复制。
- 贴图窗口支持：
  - 拖动移动、角点拖拽等比缩放、滚轮围绕鼠标缩放；
  - `⌥` + 滚轮调整透明度；
  - 右键菜单：复制文本 / 复制图片、保存、缩放、不透明度、始终置顶、隐藏、关闭；
  - 双击关闭；`Esc` / `Delete` / `⌘W` 关闭；方向键微调位置；
  - 菜单栏“显示 / 隐藏 / 关闭全部贴图”。
- 贴图不会随重启恢复；当前版本按会话管理。

### 历史与设置

- 历史记录自动保存到 `~/Library/Application Support/MyPaste/History`，保存缩略图。
- 历史窗口：缩略图网格（后台扫描列表、异步加载缩略图、LRU 缓存）、双击贴图、复制、保存、在 Finder 中显示、删除、清空、数量上限与磁盘字节上限（默认 500 MB，含缩略图占用，超出从最旧清理）；列表刷新后按记录 id 保持选中；删除 / 清空 / 记录写入失败会弹窗提示，清理失败用非模态提示条，不打断后续截图。
- 设置：三个全局快捷键的录制与恢复默认、冲突提示、失败提示（录制期间自动暂停全局热键，避免按下已注册组合直接触发截图）；声音、放大镜、自动保存、保存格式、保存目录、历史数量、历史磁盘上限、开机启动、屏幕录制权限状态。
- 设置立即生效并写入 `UserDefaults`。
- 开机启动基于 `SMAppService.mainApp`；从非“应用程序”目录运行或未签名时，系统可能拒绝注册。

## 性能

本机实测（macOS 27.0.1，arm64，内置显示器 3840×2560 / 1920×1280pt）：

| 指标 | 实测值 |
| --- | ---: |
| 空闲常驻内存 RSS | 71.4 MB（73,104 KB） |
| 空闲 CPU | 0.0% |
| 应用体积 | 2.6 MB |
| 运行时依赖 | 系统 AppKit / ScreenCaptureKit |

测量方法：应用只常驻菜单栏、无可见窗口，启动完成数秒后执行 `ps -o rss`。RSS 包含共享内存页，因此只用于相对比较。

实现上的开销控制：

- 原生 AppKit 视图与 Core Graphics 绘制，无 WebView / JS 运行时。
- 截图底图是静态图层，交互层单独重绘；选区外遮罩只绘制矩形区域。
- 放大镜像素取色使用后台构建的像素缓冲（`PixelSampler`），O(1) 读取；缓冲就绪前降级为单像素采样，首次移动鼠标不再在主线程渲染整屏。
- 已提交标注缓存为位图层，预览只重绘当前笔画；马赛克 / 模糊效果图按区域缓存，拖动不重算。
- 剪贴板惰性编码；一次截图的 PNG 只编码一次，历史与自动保存复用；保存面板确认后立即结束会话、编码写盘在后台；历史复制 / 贴图 / 保存在后台解码原图。
- 多显示器并行冻结；全屏截图只抓目标屏幕；scale 用截图像素宽度反推，兼容 HiDPI 缩放分辨率。
- 窗口检测完全由鼠标事件驱动，并做 120ms 缓存节流，没有定时器轮询。
- 设置、历史、偏好窗口全部惰性创建；历史列表后台扫描并丢弃过期结果，刷新后按 id 保持选中；缩略图异步加载、LRU 上限，窗口关闭时释放缓存。
- 历史读写统一走串行队列，条数 + 磁盘字节双重上限清理；记录路径只读文件属性、不解码图片头，单个文件清理失败不中断整轮，并回收孤儿缩略图。
- 截图会话结束后立刻释放屏幕帧、窗口和工具栏。
- 文本 / 颜色贴图在 2x 离屏上下文中渲染。

说明：本环境尚未为 MyPaste 授予 macOS 屏幕录制权限，因此没有测量真实抓屏延迟。抓屏使用系统 ScreenCaptureKit，延迟取决于显示器数量、分辨率和系统版本。

## 构建与运行

要求：macOS 14+，Xcode 15+（本项目在 macOS 27.0.1 / Xcode 27.1 / Swift 6.4 验证）。

```bash
# 构建 release .app（ad-hoc 签名）
./scripts/build_app.sh

# 运行构建产物
open build/MyPaste.app
```

本次优化后的构建产物在 `build/MyPaste.app`（ad-hoc 签名）。此前交付的版本安装在 `/Applications/MyPaste.app` 并完成过屏幕录制授权；**替换安装版本会改变签名，需要重新授权**，是否覆盖由用户决定。应用是菜单栏应用（`LSUIElement`），不会出现在 Dock。

> 注意：如果重新执行构建脚本或替换应用，ad-hoc 签名会变化，macOS 可能要求重新授予屏幕录制权限。

### 首次授权

1. 启动 MyPaste，菜单栏出现取景框图标。
2. 按 `F1` 或菜单栏“截图”。macOS 会请求“屏幕录制”权限。
3. 在“系统设置 › 隐私与安全性 › 屏幕录制”中勾选 MyPaste。
4. 如果授权后仍提示无权限，请退出 MyPaste 再重新打开（系统可能要求重启进程）。
5. 如果移动了 `.app` 或重新签名，TCC 可能需要重新授权。发布给他人时建议使用稳定的 Developer ID 签名并公证。

### 开发

```bash
swift build
swift test
swift run MyPasteSnapshots docs/snapshots
```

- `swift test`：61 个核心测试 + 44 个 UI 交互测试（含会话生命周期、提示条快照、v1.1 回归与超时竞态、v1.2 / v1.3 性能与存储回归），共 105 个，全部通过。
- `swift run MyPasteSnapshots docs/snapshots`：离屏渲染 13 张 UI 预览（含合成结果与提示条），不弹出窗口，也不需要屏幕录制权限。
- 调试时也可通过 URL 动作：

```bash
open 'mypaste://capture'
open 'mypaste://pin'
open 'mypaste://fullscreen'
open 'mypaste://picker'
open 'mypaste://history'
open 'mypaste://settings'
open 'mypaste://quit'
```

> `pin` / `fullscreen` / `quit` 由外部应用触发时会先弹出确认框，避免静默读取剪贴板或借已授权进程截取整屏；外部触发的 `fullscreen` 只写剪贴板与历史库，不自动保存到文件夹。`capture` / `picker` / `history` / `settings` 本身会显示可见界面，保持直达。

设计要点：

- 屏幕截图冻结后按显示器分别建立无边框覆盖窗口；静态底图与交互层分离，避免每次鼠标移动重绘整张截图。
- 选区、标注都在 point 坐标系中编辑，导出时按截图像素反推的 effective scale 一次性光栅化，保留 Retina 清晰度并兼容 HiDPI 缩放分辨率。
- 标注预览与最终导出共用 `AnnotationRenderer`，避免“编辑时”和“输出时”不一致。
- 所有内容在本机处理，不发送网络请求，不需要账号。

## 隐私

- 无网络代码、无分析统计、无上传。
- 截图历史默认保存在本机 `~/Library/Application Support/MyPaste/History`。
- 历史原图、缩略图与自动保存文件按 `0600`、历史目录按 `0700` 落盘。
- 屏幕内容只在内存中处理，会话结束后释放；历史文件需用户主动删除或设置上限。
- 剪贴板读写仅在用户触发截图 / 贴图时发生；外部应用通过 `mypaste://` 触发的敏感动作会先弹确认框，且不会自动保存到文件夹。
